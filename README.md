# oFatura - E-Arşiv Fatura Yönetim Sistemi

Modern ve profesyonel e-arşiv fatura yönetim sistemi tanıtım sitesi.

## Teknolojiler

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide Icons

## Kurulum

```bash
npm install
```

## Geliştirme

```bash
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

## Production Build

```bash
npm run build
npm start
```

## Özellikler

- Modern ve responsive tasarım
- SEO optimize edilmiş
- Hızlı sayfa yükleme
- Türkçe dil desteği
- oFatura markasına özel renk paleti
